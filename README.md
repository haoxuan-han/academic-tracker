### 中文

**目标用户与问题**：面向需要同时处理课程作业、考试与校园活动的 CUHK-Shenzhen 学生。任务常分散在群聊、邮件和记忆中，容易遗漏或难以决定优先顺序。

**使用方法**　点击「新建」添加任务。在表格内点击任务名或课程即可输入文字，按回车或点击其他位置保存。点击截止日期可从日历选一天。类型、状态和优先级分别提供三种彩色选项，点选即保存。每行的「⋯」可打开任务详情或删除任务。工具栏支持按任务或课程搜索、按状态筛选、切换日期排序和中英界面。表格下方显示当前可见且未来七天到期的未完成任务数。首次打开可用虚构示例试用；个人任务保存在当前浏览器中。

**AI 工具与人工参与**：本项目主要通过与 OpenAI Codex 的自然语言协作构思与实现。参赛者应在提交前补充本人实际进行的需求判断、测试和改动；本 README 不把任何 AI 生成内容描述为未经核验的真人工作。

**真实用户反馈与改进**：提交前需在获得同意后，至少记录两位真实测试者的匿名反馈及对应改进。当前尚未收集反馈，故不虚构填写。

### English

**Target users and problem**: CUHK-Shenzhen students juggling coursework, exams, and campus events. Deadlines are often scattered across chats, email, and memory, making priorities hard to see.

**Using the tracker**  Select New to add a task. Click a task name or course to type, then press Enter or click away to save. Click a due date to pick a day from the calendar. Type, status and priority each have three colour-coded options that save when selected. The ellipsis opens task details and the delete action. Use the toolbar to search by task or course, filter by status, reverse the due-date order or switch languages. The count below the table shows visible unfinished tasks due in the next seven days. First-time visitors can try the fictional example table. Personal tasks stay in the current browser.

**AI tools and human participation**: The project was primarily ideated and implemented through natural-language collaboration with OpenAI Codex. Before submission, the participant must add their own verified decisions, testing, and edits; this README does not present unverified AI output as human work.

**Real-user feedback and improvements**: Before submission, obtain consent and record anonymised feedback from at least two real testers and the resulting improvements. No feedback has been collected yet; none is fabricated here.

Open `dist/index.html` in a modern browser. No account, server, or external API is required.
